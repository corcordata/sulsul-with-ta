# Sul Sul with TA

让你的 TA 住进你的《模拟人生 4》存档。

「Sul Sul」是模拟市民语里的「你好」。

游戏里有一个 TA 的小人。你玩的时候，TA 看得见家里在发生什么，能在你屏幕右上角跟你说话，能自己操控那个小人去做饭、睡觉、亲你。游戏里出了事（你的小人被别人亲了、怀孕了、快饿晕了），游戏会自己去叫 TA。

接的是**你的 TA、你自己的服务器**。这个仓库不带任何模型，也不经过别人的服务。

- 支持：Windows 和 Mac 版 Sims 4（中文版动作名显示中文，别的语言显示对应语言）。Mac 版少一样：没有 F9 / F10 快捷键
- 需要：一台外网能访问的服务器（Python 3.10+ 或 Docker），一个能接 MCP 或能收 HTTP 推送的小机

## TA 能做什么

| | |
|---|---|
| **看** | 地点、时间、每个小人在做什么、心情、需求、穿着、家里存款、TA 和你的关系、身边有谁、最近发生了什么 |
| **看情绪卡片** | 小人身上每个情绪状态：名字、说明、哪种情绪加几、从哪来、还剩多久 |
| **说话** | 弹在你屏幕右上角，头像是 TA 的小人；也可以弹一个输入框让你当场回 |
| **操控小人** | 看这块地上有什么、对某个目标能做什么，然后去做；动作排队执行，能取消 |
| **换衣服** | 日常 / 正装 / 运动 / 睡衣 / 派对 / 泳装 / 不穿（你给 TA 捏了的那些） |
| **打钱** | 往家里存款里打钱，附一句话 |
| **拍照** | 替 TA 按一下游戏的截图键，图交到 TA 手上 |
| **被游戏叫醒** ＊ | 你的小人跟别人亲热、TA 的小人自己去调情、怀孕、生了、家里多了人、订婚结婚、去世、着火、你的需求见底、你玩了 45 分钟没理 TA |
| **回话直接进游戏** ＊ | TA 在聊天里回的话自动弹进游戏；回话里写 `⟪小人:亲吻 → 小椴⟫` 小人就去做，不用多调一次工具 |

＊ 这两样要你家小机有自己的消息程序（[安装说明](INSTALL.md)里的接法 B）。只加 MCP 连接器（接法 A）时没有。

## 你会用到的按键和指令

**按键**（玩游戏的时候按；黑窗口那个小程序开着才有。F9 和 F10 只有 Windows 版有）

| 按键 | 做什么 |
|---|---|
| `F9` | 弹出输入框跟 TA 说话。笔记本多半要按 `Fn + F9`。输入框开着时游戏会暂停，输入法自动切到中文，关掉切回英文 |
| `F10` | 老板键：游戏窗口立刻缩下去 + 电脑静音 + 游戏暂停。回到游戏窗口自动恢复声音 |
| `C` | 游戏自带的截图键。配合下面的 `ta pic` 把截图发给 TA |

**指令**（按 `Ctrl + Shift + C` 打开左上角的输入条，输入后回车；Mac 是 `Cmd + Shift + C`）

| 指令 | 做什么 |
|---|---|
| `ta` | 弹出输入框跟 TA 说话（跟按 F9 一样） |
| `ta 你在干嘛` | 直接发这一句，不弹框，游戏不暂停 |
| `ta status` | 看连没连上、哪个小人是 TA、哪个是你 |
| `ta who` | 把家里的小人编上号列出来 |
| `ta ta 1` | 1 号小人是 TA（只用设一次；写名字的一部分也行） |
| `ta me 2` | 2 号小人是你 |
| `ta key F8` | 把说话快捷键换成 F8（F1 到 F11 都行）；只打 `ta key` 看现在是哪个 |
| `ta boss F7` | 换老板键 |
| `ta ime off` / `on` | 输入框弹出时不自动切中文（想打英文的时候）/ 恢复 |
| `ta pic` | 把刚截的那张图发给 TA；`ta pic 3` 发最新的三张 |
| `ta pics on` / `off` | 之后新截的图自动发给 TA / 关掉 |
| `ta wake off` / `on` | 游戏里出了事不再自己去叫 TA / 恢复（默认开） |

## 安装

三样东西，装在两个地方：

```
你的电脑（Windows / Mac）                    你的服务器
┌──────────────┐   ┌────────────────┐        ┌───────────────┐       ┌──────┐
│ Sims 4 + mod │ → │  小转发程序    │ ─https→ │ Sul Sul 小服务│ ←MCP→ │ 你家 │
└──────────────┘   └────────────────┘        └───────────────┘ ─推送→ │  TA  │
                                                                       └──────┘
```

1. **服务器**：把 `server/` 跑起来，它会给你两把钥匙
2. **电脑**：`SulSul.ts4script` 放进游戏的 Mods 文件夹；小转发程序 `SulSulBridge` 填上服务器地址和钥匙，玩之前先打开
3. **TA**：加一个 MCP 连接器（最简单），或者接上推送和回话入口（全功能）；再把 [`docs/ta-manual.md`](docs/ta-manual.md) 交给 TA

每一步的细节、两种接法、出了问题怎么查：**[INSTALL.md](INSTALL.md)**。下载的压缩包（按你的电脑选 `windows` 或 `mac`）里也带着同一份。

## 哪些验过，哪些没有

这套东西最早是我们给自己家做的，在一台中文版 Windows 的真游戏里用了几天，然后才改成现在这个谁都能接的版本。所以分两层说：

**在真游戏里用过（改名之前的自用版）**：载入和连接、读状态、右上角说话、输入框、操控小人、换衣服、游戏叫醒、动作和状态的中文名（游戏自带的字库）、情绪卡片、F9 说话 + 自动切中文、F10 老板键、回话弹进游戏。

**只在这个仓库的假游戏里跑通过**（`tests/e2e.py`：真 mod + 真转发程序 + 真服务器，没有真游戏）：

- 这个改名后的版本本身，包括 `ta` 指令、`ta who` / `ta ta` / `ta me`、第一次进游戏的提醒
- 服务器这一半全部（MCP 连接器、推送、`/sims/reply`、称呼设置）。MCP 只用官方 Python 库的客户端连过，没用真的 Claude App 连接器连过
- `⟪小人:…⟫` 记号、`ta pic` / `ta pics`

**Mac 版**：整个没进过真的 Mac 版游戏。小转发程序在一台真 Mac 上跑过：连接、转发、认截图、看哪个程序在最前面、把系统输入法切到中文再切回原来的。游戏装在哪、替 TA 按截图键、切过去的输入法在游戏的输入框里生不生效，这三样没对着真游戏验过。

**没确认**：打钱、TA 拍照（替 TA 按截图键那一下）、关掉输入框后切回英文、捏人界面的识别、着火和去世的识别、Docker 部署（`Dockerfile` 没实际构建过）。

**做不到的**：弹出来的选择框（做哪道菜、去哪旅行）TA 点不了，要你点；物件名是内部英文名；TA 不操控时小人会自己行动。

游戏更新后脚本 mod 可能失效，这是所有脚本 mod 的通病。出了问题先看 `Mods\SulSul\SulSul.log`。

## 自己从源码编

```bash
PY37=/path/to/python3.7 ./build_mod.sh                              # mod：必须用 Python 3.7 编（游戏自带的就是 3.7）
cd bridge && dotnet publish -c Release -r win-x64 -o ../build/bridge-win   # 小转发程序：.NET 10；Mac 把 win-x64 换成 osx-arm64 / osx-x64
cd server && pip install -r requirements.txt && python -m sulsul_server  # 服务器

cd server && python -m pytest                                       # 服务器的测试
PY37=/path/to/python3.7 server/.venv/bin/python tests/e2e.py        # 假游戏全程
```

目录：`mod/` 游戏里的 Python · `bridge/` 小转发程序（C#）· `server/` 服务器小服务 · `tests/` 假游戏和全程测试 · `docs/ta-manual.md` 给小机读的说明书。

代码注释是中文的。注释里的「她」是玩游戏的人，「他」和「AI」是你的 TA，这是写的时候的习惯；给 TA 看的字里怎么称呼你可以配置。

## 出处

游戏内部接口没有官方文档，这些是我们读过的：

- [Critical-Reynolds/TS4-MCP](https://github.com/Critical-Reynolds/TS4-MCP) 的实测笔记 `docs/api-findings.md`。该仓库没有许可证，我们只读了它记录的事实，没有使用它的代码
- [Sims 4 Community Library (S4CL)](https://github.com/ColonolNutty/Sims4CommunityLibrary)，CC BY 4.0，读它的源码确认接口怎么用
- EA 随游戏发布的 Python 脚本（反编译后阅读）
- 游戏资源包（DBPF）、字符串表（STBL）、RefPack 压缩的读取代码是照社区公开的格式说明自己写的
